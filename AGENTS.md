# AI4SE Labs 2026

## Repository purpose

This repository contains semester assignments for Software Engineering with AI. Complete only the tasks requested for the specified week.

## Working rules

- Change only the files requested as output for the active assignment.
- Read the relevant `Task_*.md` file before creating output files.
- Preserve existing reports and solution files unless the assignment explicitly requires a change.
- Use Markdown for written reports and keep submissions concise.
- Avoid installing dependencies or changing source code unless the requested task requires it.
- Before finishing, verify that all required deliverables exist at the paths specified by the assignment.

## Repository layout

- `Week_*_*/Assignments/` contains assignment instructions and task outputs.
- `Week_*_*/Tasks/` contains weekly tasks and their outputs.
- `Week_*_*/Task_*/` or `Week_*_*/Assignments/Task_*_/` contains task-specific instructions and deliverables.
- `Task_*.md` is the assignment specification.
- `report.md` is commonly used for a short written submission.
