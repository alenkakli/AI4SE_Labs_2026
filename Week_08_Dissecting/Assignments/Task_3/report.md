I am using GitHub Copilot in Visual Studio Code. I did not find a built in `/init` slash command that creates repository summary files in my setup, so I initiated creation with a direct prompt asking the assistant to inspect the repository and create an `AGENTS.md` file. I used the repositorys existing guidance and task structure to keep the file concise and to limit it to relevant working rules.

Here is the github website again, because I found it relevant to this task also [Github Docs](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/add-custom-instructions/add-repository-instructions). The `AGENTS.md` file serves a similar purpose as the alternative option for the system prompt I did in Task 1. The main difference being that there can be multiple of these files and for the agent the nearest `AGENTS.md` file in the directory tree takes precedence. Here is more information on [AGENTS](https://github.com/agentsmd/agents.md).
